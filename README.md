Project Title
 PEACI School Supplies Catalog System

Project Purpose
The purpose of this project is to create a system that displays different school supplies in an organized and accessible catalog. It will help students, parents, and teachers easily browse school supplies, view product details, and check their prices. The system aims to make finding and selecting school materials easier and more convenient.

Planned Features
1. Product Listing – Displays a collection of available school supplies, including their names and pictures.

2. Product Details – Shows information about each school supply, such as its name, description, category, and price.

3. Product Categories – Organizes school supplies into categories such as writing materials, paper products, art materials, and school accessories.

4. Search Feature – Allows users to search for specific school supplies by typing the product name.

5. Price Display – Shows the prices of each school supply to help users compare and choose products.
